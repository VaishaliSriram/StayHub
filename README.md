# StayHub – Vacation Rental Web Application

## About the Project

StayHub is a vacation rental web application inspired by platforms like Airbnb. It allows users to explore property listings, view property details, write reviews, and make basic booking requests. Property owners can add, edit, and manage their property listings.

## Features

- **User Authentication:** User registration and login using Passport.js and Express sessions.
- **Property Listings:** Create, view, edit, and delete property listings.
- **Search Properties:** Search for properties based on details such as location and title.
- **Property Details:** View property descriptions, prices, locations, and images.
- **Image Uploads:** Upload property images using Multer and store them with Cloudinary.
- **Reviews:** Add ratings and comments for properties.
- **Basic Booking:** Submit booking details for selected properties.
- **Form Validation:** Validate property data using Joi.
- **Flash Messages:** Display success and error notifications.
- **Error Handling:** Handle application errors using Express middleware.

## How It Works

1. Users register or log in to the application.
2. Users browse available property listings and search for properties.
3. Property owners can add new properties with descriptions, prices, locations, and images.
4. Property information is stored in MongoDB Atlas using Mongoose.
5. Property images are uploaded to Cloudinary, and their URLs are saved with the listing data.
6. Users can view property details, submit reviews, and use the basic booking flow.
